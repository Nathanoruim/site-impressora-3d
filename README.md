# 🚀 PrintLab

O hub definitivo para testes e calibração de impressão 3D.

O PrintLab foi criado para organizar modelos STL de calibração, benchmarks e testes técnicos utilizados na impressão 3D FDM. O objetivo é facilitar a vida de makers, estudantes, profissionais e entusiastas que desejam encontrar rapidamente os melhores testes para suas impressoras e filamentos.

---

# ✨ Objetivo do projeto

O projeto busca centralizar:

- Benchmarks de impressão 3D
- Testes de calibração
- STL organizados
- Recomendações de configuração
- Materiais compatíveis
- Guias técnicos
- Futuras análises inteligentes com IA

---

# 🧪 Testes disponíveis

## 🚢 Benchy
Benchmark completo para analisar:
- qualidade geral
- precisão
- overhang
- bridging
- vibração
- retração

---

## 🌡️ Temp Tower
Teste térmico utilizado para:
- calibrar temperatura
- reduzir stringing
- melhorar acabamento
- otimizar adesão de camada

---

## 🧵 Retraction Test
Utilizado para:
- calibrar retração
- eliminar stringing
- reduzir blobs
- melhorar movimentos de travel

---

## 📐 Overhang Test
Teste de inclinação para:
- validar cooling
- descobrir limite sem suporte
- melhorar superfícies inclinadas

# 📦 Instalação

Clone o projeto:

```bash
git clone https://github.com/seuusuario/printlab.git
```

Instale as dependências:

```bash
npm install
```

Inicie o servidor:

```bash
npm run dev
```
